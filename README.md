HRA-MOEA/D-Based Resource-Aware CPS Framework for Smart Grid Security
Overview

This repository contains the Python implementation of a Hybrid Resource-Aware Multi-Objective Evolutionary Algorithm based Cyber-Physical System (CPS) framework for smart grid applications.

The framework integrates:

Smart Grid CPS Dynamic Modeling
Cyber Attack Modeling and Mitigation
Resource-Aware Event Triggered Control (RA-ETC)
Edge–Cloud Hierarchical Aggregation
ADMM-Based Distributed Optimization
HRA-MOEA/D Multi-Objective Optimization
CPS Performance Evaluation
Key Features
Real-time CPS state monitoring
Cyber disturbance modeling
Adaptive resource allocation
Edge-to-cloud coordination
Multi-objective optimization
Event-triggered communication
Security-aware CPS control
Smart grid resilience analysis
Performance Metrics

The framework evaluates:

Latency,Throughput,Delay,Error Rate,Energy Cost,Energy Consumption,Attack Impact,Safety Metric,Fairness,Stability Index,Resilience Index,CPS Loss,Resource Utilization
Load Balancing,Utility,System Reliability,Node Criticality,Convergence Speed

Requirements:
Python 3.10+
NumPy
Pandas
Matplotlib

Install dependencies: pip install numpy pandas matplotlib

Dataset
The implementation uses the eCO2mix smart grid dataset for power system analysis and CPS simulation.
